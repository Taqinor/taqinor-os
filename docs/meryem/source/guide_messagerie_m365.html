2. Lire et envoyer des mails sur PC

Outlook s’utilise dans le navigateur : outlook.office.com.

L’application « Outlook » du Microsoft Store (le « nouvel Outlook ») affiche « Ce compte n’est pas pris en charge » avec notre licence. Ce n’est pas une panne : cette application n’est pas incluse dans Business Basic. La version web fait exactement la même chose.

Transformer Outlook web en application de bureau (recommandé)

Dans Chrome ou Edge, avec outlook.office.com ouvert :

  1. Menu ⋮ (en haut à droite) → Enregistrer et partager (ou Plus d’outils) → Installer la page en tant qu’application (Chrome) / Applications → Installer ce site en tant qu’application (Edge).
  2. Valide : une icône Outlook apparaît sur le Bureau et dans le menu Démarrer, et Outlook s’ouvre ensuite dans sa propre fenêtre, sans onglets.

Réglages à faire une fois

  • Signature : Paramètres (roue dentée) → Comptes → Signatures. Modèle : Meryem Hida — TAQINOR · meryem.hida@taqinor.ma · +212 …
  • Réponses automatiques (congés) : Paramètres → Comptes → Réponses automatiques.
  • Langue et fuseau horaire : Paramètres → Général → Langue et heure → Français, (UTC+01:00) Casablanca.

3. Les boîtes partagées contact@ et stages@

Tu peux lire ces boîtes et envoyer en leur nom.

Les afficher dans Outlook web

  1. Dans la colonne de gauche, clic droit sur meryem.hida@taqinor.ma → Ajouter un dossier ou une boîte aux lettres partagée.
  2. Tape contact puis Ajouter. Recommence avec stages.
  3. Les deux boîtes apparaissent sous ton compte, avec leurs dossiers Boîte de réception / Éléments envoyés.

Répondre depuis contact@ ou stages@

  • Dans un nouveau message, clique sur De (au-dessus de l’objet) et choisis l’adresse partagée. Si De n’apparaît pas : … (trois points) de la barre du message → Afficher De.
  • Quand tu réponds à un mail arrivé dans la boîte partagée, Outlook choisit déjà la bonne adresse.

Bon usage : un mail traité dans contact@ ou stages@ est marqué comme lu ou déplacé dans un dossier (ex. Traité), pour que Reda et toi ne répondiez pas deux fois.

4. Sur le téléphone (Android ou iPhone)

  1. Installe Microsoft Outlook (Play Store / App Store).
  2. Ouvre-le, saisis meryem.hida@taqinor.ma, puis le mot de passe.
  3. Les mails, le calendrier et les contacts se synchronisent. Pour voir contact@ et stages@ : Paramètres → Ajouter un compte de messagerie → Ajouter une boîte aux lettres partagée → contact@taqinor.ma (puis stages@).

Les notifications arrivent en temps réel. Tu peux aussi utiliser l’application Mail du téléphone en ajoutant un compte Exchange / Office 365 avec les mêmes identifiants, mais l’application Outlook gère mieux les boîtes partagées.

6. Sécurité : les règles à respecter

  • Ne communique jamais ton mot de passe, même à quelqu’un qui dit être Microsoft ou l’informatique. Microsoft ne le demande jamais par mail ou par téléphone.
  • Un mail qui demande de « vérifier le compte », « mettre à jour le paiement », avec un lien et un ton pressant : ne clique pas, transfère-le à Reda.
  • Pièces jointes inattendues (.zip, .exe, factures d’inconnus) : ne pas ouvrir.
  • Verrouille le PC quand tu t’absentes (touche Windows + L).
  • Si tu changes de téléphone ou perds le tien : préviens Reda, il coupe l’accès de l’ancien appareil depuis l’administration.
