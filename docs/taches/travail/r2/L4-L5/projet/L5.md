# go-deep L5 « all the way » — what L5 adds to L4

Read `L4.md` first, then this file, in full, before tour 0. L5 runs everything in L4 and adds the
items below. Values tagged **(start)** are starting values, not calibrated; nothing here is
measured yet — the first L5 measures it and writes it to the state file.

## Frame

- **Launched only when Reda names it** (« go L5 », « go all the way »). Never auto-picked, never
  reached by escalation.
- **A campaign over several sessions BY NATURE** (days of real use, weekly quota windows). Each
  session ends at a merge (Claude stops at the merge); the state file (`gabarits/etat.md`) is the
  resume point. Each session first gets its bearings: `git fetch`, read the state, replay the
  baseline e2e, renew the claims — then works.
- **Cost line**: « L5 — coût non mesuré ; en plus de L4 : une lane de figeage, des relecteurs en
  plus, <durée> de Reda sur son appareil, au moins deux fenêtres hebdomadaires. »
- **Fable**: up to the house 1-3 cap, only CLAUDE.md's cases (a)(b)(c) — the final critique (a),
  an adjudication two opus passes could not settle (b). No other Fable pass.

## What L5 adds (each with who, what, when)

1. **Freeze before touching** (freeze lane, sonnet, at tour 0, before any fix). EXISTING:
   characterization goldens of every served number AND gesture in scope, recorded on the intact
   commit, locked in CI; a fixing lane never updates them (a deliberate change is named in the
   contract's K10). NEW: the promise list as data, every entry failing, each with its oracle,
   before code. MIXED: goldens of the touched surface; the new half passes ITS acceptance AND the
   old goldens hold.
2. **Compose** (orchestrator, at each consolidation). Every class guard is proved RED on the
   commit that introduced the defect before it counts (`gabarits/fiche-invariant.md`). Each
   proven reviewer journey becomes `frontend/e2e/acceptation/<g>.spec.js`, written AFTER the
   finding; critical journeys run k = 3 times, all green (pass^3: a 75 % journey passes three in a
   row ≈ 42 % of the time; k = 3 is a design choice, source in `conception.md`).
3. **WebKit for iPhone journeys** (reviewers on the phone axis). `frontend/playwright.config.js`
   on `main` has a `mobile-safari` WebKit project that runs only `mobile.spec.js`; whether a
   WebKit engine is installed on this box and can drive the scope's journeys is CHECKED at tour 0,
   never assumed. In L4 too when it is there.
4. **A simulated week** (one reviewer, for any module with a rhythm: tasks, follow-ups, due dates).
   On a seeded account, advance the clock day by day and replay the daily loop 7 times; findings
   are registry rows like any other.
5. **Real-life stage** (Reda's gestures, listed in the report, never done by Claude): the deploy,
   the activation flag in prod, Reda on his own device for <30 min> **(start)** of written
   journeys, <5 days> **(start)** of real use, <3> **(start)** debrief questions. Then, after his
   deploy, read prod READ-ONLY (standing approval `docs/claude-memory/prod-read-access.md`): the
   module's errors and usage. The anonymised dataset (qa-explorer `dataset: anon`) only when the
   main stack is free, loaded by Reda or by qa-explorer's own command on its stack; its captures
   stay in the scratchpad, never on a pushed branch, and no amount goes into the registry.
6. **Independent judges** (L5 rounds). Beauty by two blind reviewers on pairs against a named
   reference, agreement reported, anchored on a starting set of cases Reda scored once (size
   **(start)**). Another model family on S1-S2 findings and the server diff only with Reda's yes
   (paid dependency).

## Experiments — reported, never a decision

- **What remains**: two reviewers on one common stratum (two central screens), same build:
  Chapman N = (n+1)(K+1)/(k+1) − 1, shown as a range and as a « lower bound », unstable with few
  common findings. Seeded defects → recall, as an experiment.
- **Harness revalidation**: on a new model, remove ONE component, rerun a known round, keep it only
  if it still pays. Without effect in a single-model campaign; never a Fable pass.

## Stop

As L4, plus: the campaign stops at ≤ 5 rounds **(start)** + the real-life stage, or when the
« not worth it » cases of `SKILL.md` hold. The report lists what Reda still has to do himself.
