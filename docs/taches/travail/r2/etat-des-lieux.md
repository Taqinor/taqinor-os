- **Copilote** : quatre demandes prêtes sans clé d'IA (planifier, prioriser, coller une liste, faire le point) ; conversation libre avec clé.
- **iPhone** : « Mon iPhone » en 5 étapes, pastille, notifications (plan du matin, message de 15 h, bilan, rappels), calendrier abonné, capture Siri par jeton, tuile Scriptable, Aujourd'hui en accueil.

- **Notifications push réelles** : le serveur émet (TCH171 joué à heure forcée) ; une notification reçue sur son écran verrouillé, jamais. `VITE_VAPID_PUBLIC_KEY` et `NOTIFICATIONS_TOUJOURS_IMMEDIATES` en production : non lus.
- **Calendrier abonné** : l'adresse `webcal://` jamais ouverte dans Calendrier (README ; revue-code-f3 n° 13).
- **Siri** : le raccourci n'existe pas (il vit dans le compte Apple de Reda) ; seule la route `capture/` a été jouée avec `curl`. **Scriptable et la grande tuile** : forme JSON et script testés, jamais posés sur un écran d'accueil (README).
- **Copilote en production** : jouée avec le vrai assistant sur un runner GitHub (17 étapes sur 17, `docs/audits/acceptation/TCH/2026-11-18-60c17af83.md`) ; clé et fournisseur de production non vérifiés (la mémoire partagée note un Groq de production fragile : `docs/claude-memory/tokens-ia-commerciaux.md`). Ce que Reda obtient sur api.taqinor.ma : non établi.
- **Le compte réel de Reda** : après le deploy du 18/11 (16 h 34 UTC) la tuile est dite visible du rôle Directeur (Passation) ; ce que Reda voit lui-même n'est pas consigné. Le correctif #1471 n'est pas déployé.
- **Beauté** jugée par un agent contre les maquettes (65 écarts, 46 corrigés), jamais par Reda ni sur appareil ; captures dans un Chromium aux fuseaux périmés (Passation).
- **Usage réel** : rythme, message de 15 h, bilan n'ont tourné que sur un semis à horloge figée, jamais sur une vraie semaine.
