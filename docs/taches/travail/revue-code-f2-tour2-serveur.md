- Projet négligé : fenêtre `]J − 14, J]` à l'écran des projets, `[J − 14, …` la nuit (un jour d'écart).
- `services/journee._clore_pour` : `plan.save()` de tous les champs sans verrou (un bilan d'hier enregistré à 03:00 pile serait écrasé).
- `poser_preference` : sans `ReglagesRythme`, deux envois simultanés de la même clé peuvent lever une erreur d'unicité.
- `seed_taches_demo` : un compte `demo_taches` qui existerait dans une autre société serait déplacé dans la société de démonstration (hors production seulement).
- `sous_taches.total` d'un ITEM compte les sous-tâches abandonnées, alors que l'avancement d'un projet les exclut.
- `_minutes_prevues` compte une tâche du jour rangée dans À revoir.
