L'inventaire complet des `.objects` du module est fait.
- **Mes données / Tout effacer** : limités au couple société × utilisateur. `records` n'est pas touché. Les jetons et l'URL d'un agenda externe sont exclus par liste blanche. `soft_delete(record=False)` partout : rien ne va dans la corbeille de l'ERP. `__str__` est neutre.
- **SSRF des agendas** : https seul, toutes les adresses résolues revérifiées, connexion épinglée sur l'IP vérifiée (le nom ne sert qu'au TLS), redirections revérifiées, corps ≤ 2 Mo, URL jamais journalisée ni rendue, cache par société + agenda + empreinte. Vérifié en mémoire : `::ffff:127.0.0.1`, `::ffff:169.254.169.254`, `64:ff9b::7f00:1`, `fe80::1%eth0` et `fd00:ec2::254` sont tous refusés.
- **Nuit** : jour local `Africa/Casablanca` (`CELERY_TIMEZONE`, `ENABLE_UTC=False`, `timezone.localdate()`). Seuls les comptes qui ont des `ReglagesRythme` sont traités. Une étape en échec n'arrête ni les autres étapes ni les autres sociétés. Les purges sont datées et rejouables.
- **Fichiers ERP touchés** : `records/selectors.py`, `crm/selectors.py`/`dsr_provider.py` (ajouts en lecture seule), `authentication/selectors.py` (une route de plus), `roles` (`taches_voir` à l'Administrateur seul, propagé par `init_roles` dans `scripts/auto-deploy.sh:321`), `celery.py`/`settings` (une tâche planifiée, file `scheduled`), `RolesManagement.jsx`, palette et raccourcis (entrées filtrées par `isPathVisible`).
