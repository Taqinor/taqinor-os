Mon iPhone

Cinq réglages pour retrouver tes tâches partout sur l'iPhone. Chacun se défait ici, à tout moment.

2 sur 5
    1. Copie l'adresse, puis ton jeton.
    2. Dans Raccourcis : + → « Obtenir le contenu de l'URL ».
    3. Colle l'adresse ; colle le jeton dans l'en-tête.
    4. Nomme-le « Ajoute une tâche ».

    Ce jeton ne sait qu'ajouter une tâche pour toi. Perdu ? Tu le régénères ici.
