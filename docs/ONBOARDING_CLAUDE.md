# Onboarding Claude Code — nouvel équipier TAQINOR

La façon de travailler (WOW) vit à deux endroits :

1. **Ce dépôt** — `CLAUDE.md` (règles + commandes « work on the plan »…), `.claude/settings.json`
   (modèle, hooks, permissions), `.claude/skills/` (go-deep, error-autopilot). Chargés
   automatiquement quand Claude Code est ouvert dans `C:\dev\taqinor-os`.
2. **Le dépôt privé `Taqinor/taqinor-memoire`** — mémoire persistante de Claude (règles fondateur,
   pièges, backlogs), états de discussion `sessions/`, conversations `transcripts/`, livrables
   `documents/`. À cloner dans `%USERPROFILE%\.claude\projects\C--dev-taqinor-os\memory`.

Le pas-à-pas complet (invitation GitHub, message unique à coller dans la première session,
règles de mémoire partagée, partage d une discussion entière) est dans le README de
`taqinor-memoire`, section « Nouvel ÉQUIPIER ».
