## 5. Parcours de référence

### 5.1 Reonic — le plus court de bout en bout (documenté, https://docs.reonic.com/docs/en/offers-plan-pv-plan-building et .../offers-plan-pv-plan-modules)
Comptage de saisies OBLIGATOIRES : mon décompte à partir des pages lues (pas un chiffre publié par Reonic).
1. **Requête / Offre** (CRM, 2 écrans) : adresse du projet + client + type de projet = **3 saisies**. L'éditeur centre la carte sur l'adresse (« Check that the project address is correct »).
2. **Onglet « Planning » → « Start planning »** → choix du mode (**Quick planning** prix seul, sans 3D, ou **3D planning**) → « Begin planning » = **1 choix**. Carte « 3D with Google Data » = source 3D choisie seule ; paquet de planification (module + onduleur + accessoires) importable en un geste = **1 choix** (module).
3. **Éditeur Plan3D, phase « Building »** : tracer le toit par clics (Smart Roof ou Flat Roof) ; **Building AI** (si activé) propose contours, lucarnes, arbres ; relecture obligatoire ; saisie d'une **inclinaison** par toit (1 valeur) ; retrait en cm (30-50 typique, facultatif) ; zones d'exclusion (cheminée = hauteur 0,5 m par défaut) = **1 saisie** + clics.
4. **Phase « Modules »** : **« Cover roof side »** (1 clic par face, 80-90 % du résultat) ; « Optimieren » (IA) optionnel ; retirer des modules au clic = **0 saisie**.
5. **Phase « Strings »** : **Add Inverter** (catalogue) → **Generate Strings** (options : même orientation, longueur maxi) ; alertes en ligne (courant MPPT, orientations mixtes) = **1 choix** (onduleur).
6. **Simulation** : panneau « éclair » (rendement, autarcie, investissement, retour) en direct ; **Simulate Shading** (1 clic) → perte annuelle + graphe mensuel ; **Schéma de circuit** généré tout seul à la première ouverture ; **vues** pour le PDF (jusqu'à 4 + 1) ; **Finalise** → envoi pour signature.
Total lu : ~**6-8 saisies obligatoires**, 4 gestes de calcul d'un clic (Cover, Generate Strings, Simulate Shading, schéma). Ce que la page ne dit pas : durée réelle.

### 5.2 Scanifly SimpleDesign — le plus simple pour un vendeur (https://scanifly.com/blog/introducing-simpledesign/)
1. **Adresse** (1 saisie) + **type de module** (1 choix) → calepinage IA généré « à la table de cuisine ». 
2. **Niveau 1 (Grille)** : basculer des modules ou des pans entiers ; garde-fous (arbres, retraits, obstacles). **Niveau 2 (Manuel)** : déplacer, copier, orienter, toujours dans les retraits.
3. **Comparer** à un modèle drone (facultatif) puis **exporter** vers l'outil de proposition. 
Total : **2 saisies obligatoires**, production et couverture de facture en direct. (Pages de documentation détaillées non lisibles : voir § 6.)

### 5.3 SolarEdge Designer (https://canalsolar.com.br/en/solaredge-designer-modeling-and-positioning-of-modules/, article tiers, 10 étapes)
Adresse ou coordonnées (1) → polygone du toit (clics) → « Inner edges » (auto : lignes de pente) → obstacle 2 points + hauteur en 3D → zone de modules + arête de référence (1 clic) → inclinaison/azimut déduits (auto) → rectangle = pose automatique → 3D « à montrer au client ». Chaînage et simulation sont dans des articles suivants (non lus). Saisies obligatoires : **adresse + polygone + arête de référence**.

### 5.4 Le parcours d'ingénierie le plus complet — HelioScope (https://help-center.helioscope.com/hc/en-us/articles/4417518804115-1-Create-a-Project et les 4 articles suivants de « 5 Steps to Success »)
1. **Create a Project** : nom + adresse (ou lat/long décimale) + positionner la carte = **2 saisies**.
2. **Create a Design** : nom, copie éventuelle d'un design existant = **1 saisie**.
3. **Mechanical Layout** (Mechanical tab) : *Field Segment* tracé (clics ; Maj = 45°) → module (remplissage auto) → racking (affleurant / fixe / est-ouest / carport) → azimut (clic droit sur une arête) → inclinaison → retraits (lignes d'exclusion) → pas entre rangées → alignement → *Keepouts* (obstacles, arbres, acrotère avec hauteur ; exclusion d'ombre solstice 10h-14h) → *Advanced › Shading › Optimize shaded modules* = **≈ 9-11 saisies** (module, racking, azimut, inclinaison, retrait, pas, alignement, hauteurs).
4. **Electrical Design** : onduleur (compte auto à 125 % DC/AC) ; longueurs de chaîne depuis ASHRAE ; zones de câblage ; combineurs ; AC (optionnel : tableaux, transformateurs) ; SLD généré = **≈ 2-4 saisies**.
5. **Simulation and Report** (Reports tab) : *Condition Set* (météo la plus proche par défaut, ombrage, pertes ; P90 en Pro) → « Simulate » → Production Report + **Shade Report** (TOF, accès solaire, TSRF par module) + CSV horaire + DXF + SLD DXF = **0-2 saisies** si le jeu de conditions par défaut convient.
Total (mon décompte sur les articles lus) : **≈ 14-18 saisies** en 5 étapes pour un système complet. Là se tient l'écart avec Reonic.

### 5.5 Engineering électrique la plus profonde — PVcase Roof Mount (https://help.pvcase.com/hc/en-us/articles/35594211918995 « Electrical design menu » ; .../44169203196179 « Stringing » ; .../44231655047443 « Cabling »)
Menu « Electrical design » en 5 onglets : Inverters (modèle, placement toit/intérieur, élévation) → Stringing (rangée/U/serpentin/personnalisé ; optimiseurs 1 par 2 modules ou 1 par module) → Inverters configuration (MPPT, distribution égale/auto/manuelle) → Cable trays → Cabling (« Create cabling », sans boucles d'induction, polarité, chemins ou plus court) → SLD imprimé. Tournant sur AutoCAD (donc non reproductible tel quel dans un navigateur, mais les ÉTAPES sont la référence de l'étape « Électrique » à fusionner en un seul écran, ACAL395).

### Ce que cela change pour le chemin en 5 étapes du fondateur
Les trois parcours courts (Reonic, Scanifly, SolarEdge) ont **un seul geste de calcul par étape** (« Cover roof side », « Generate Strings », « Simulate Shading ») et **aucune saisie technique** avant le premier résultat ; HelioScope en demande ~16 et c'est son point faible pour les vendeurs. L'étape Électrique de Reonic = 1 choix (onduleur) + 1 clic (générer) ; celle de HelioScope = 4 réglages. Nos 5 étapes (Toit, Panneaux, Électrique, Résultats, Documents — ACAL386/392/393) sont donc cohérentes avec Reonic ; le budget visé par ACAL478 (« ≤ 5 étapes, 0 saisie technique obligatoire ») est plus strict que Reonic (6-8 saisies) : l'écart à fermer par défauts sourcés (ACAL387/403/404/405) et par N5 (mode salon), N1/N3 (défauts de toit plat) et N6 (« Prêt à envoyer ? »).
