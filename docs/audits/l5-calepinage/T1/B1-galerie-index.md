# Galerie B1 — module Calepinage, bureau 1440 × 900, Clair et Sombre (21/11/2026)

Pile l5cal (origin/main@da49cb55b), compte rev_b1. Calepinages : 2 = B1 Villa Casablanca (toit ~1 362 m²), 4 = B1 Villa Marrakech (toit ~873 m², obstacle polygonal, enregistré), 6 = B1 Villa Agadir (plein sud, module Jinko, onduleur désigné). Fond de carte NEUTRE (clé factice, imagerie 403 — attendu).
Suffixes : -clair / -sombre = thème choisi dans le bandeau ; -entiere / -page-entiere = fenêtre agrandie à la hauteur du contenu ; -panneau = capture du seul panneau d’onglet (peut être tronquée sous le pli) ; onglet-<cle> = onglet du rail ouvert par un clic réel.

Note : dans l’atelier, les captures Clair et Sombre sont quasi identiques — c’est le constat T1-B1-001 (3,94 % de pixels différents dans la zone atelier).
