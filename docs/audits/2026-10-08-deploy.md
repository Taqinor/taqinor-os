- S-1 : une garde `check_*` qui ne peut pas échouer (motif jamais rencontré, allowlist qui avale tout, non branchée dans la CI).

Seuils : S1 déploiement cassé / donnée perdue / secret exposé ; S2 porte de CI inopérante ; S3 contournement ; S4 cosmétique.
