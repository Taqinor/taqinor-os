Réponses de Reda (02/10/2026) aux questions de l'audit L3 du devis agricole (pompage solaire). Elles fondent le
Groupe AGR (docs/PLAN.md) et le Groupe AGW (docs/WEB_PLAN.md).

- **D-AGR-1** Moteur SERVEUR agricole ouvert maintenant (volet agricole de QJR113 : dimensionnement, composition,
  économies). QJR113 reste gaté pour industriel/commercial.
- **D-AGR-2** Document client agricole dédié de 3 pages (eau + argent / comment ça marche / équipement, prix,
  garanties, signature) ; le une-page reste la version courte. DV1 (30/08) supprimait du code mort, pas le besoin.
- **D-AGR-3** Taille : volume déclaré par le client d'abord ; sinon besoin FAO-56 corrigé, étiqueté « besoin
  agronomique plein ».
- **D-AGR-4** Visite « relevé du point d'eau » AVANT le devis quand le niveau d'eau ou le débit du forage est
  inconnu après l'appel ; sinon devis comme aujourd'hui.
- **D-AGR-5** Économies = chiffres déclarés du client (bouteilles/litres × prix payé × mois d'irrigation) moins
  l'entretien solaire ; horizon 10 ans ; pompe remplacée à l'année 7 au prix réel de sa ligne ; variateur
  seulement à la fin de sa garantie écrite ; retour sans aide déduite ; bloc omis si rien n'est déclaré.
- **D-AGR-6** Aide FDA : on imprime la règle (conditions, plafonds, accord avant travaux, versement après), jamais
  un montant propre au client ; « jusqu'à 30 % » retiré partout.
- **D-AGR-7** Deux cas : pompe neuve fournie OU pompe existante conservée (variateur + panneaux sur sa plaque).
- **D-AGR-8** Kit « minimum + options » : d'office pompe (si neuve), variateur, panneaux, structure ; le reste en
  options nommées (protections, sonde marche à sec, compteur d'eau, câble de descente, colonne, clapet,
  tuyauterie, bassin) ; forage et génie civil « non inclus ».
- **D-AGR-9** Le type du lead n'est jamais changé automatiquement par un devis agricole : un bandeau alerte.
- **D-AGR-10** Aucune réalisation de pompage réelle à ce jour : preuve J4 omise pour l'agricole, jamais un toit.
- **D-AGR-11** Darija : toutes les variantes pompage écrites maintenant ; relecture par Reda après.
- **D-AGR-12** Priorité normale dans la file.
- **D-AGR-13** Les anciens devis agricoles sont OUBLIÉS : aucun essai à blanc, aucune réparation, aucune
  compatibilité ascendante ; seuls les nouveaux devis doivent être bons.

**Why:** tranchées en séance interactive le 02/10/2026 sur la base de constats vérifiés (code, production en
lecture seule, sources primaires : CGI 2026, Guide FDA 2024, loi 82-21, FAO-56, Banque mondiale 2018).
**Ajout du 08/10/2026** : AGR609 — l'écart de la recette pompage se mesure contre le débit PROMIS figé du devis ((mesuré − promis) ÷ promis), pas contre le débit attendu à la HMT mesurée.
**How to apply:** ne pas les re-demander ; toute tâche agricole les applique. Restent ouverts (manuels, pas des
décisions de produit) : avis écrit du fiscaliste sur la TVA du kit, prix des pompes OSP (QXG3), garanties écrites
des fournisseurs, confirmation DPA du processus FDA. Voir [[qjr5-decisions-fondateur]], [[kwh-declare-vs-factures]].
